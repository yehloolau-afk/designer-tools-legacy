# Designer Tools Legacy

Historical archive for early single-file designer tools and compatibility redirects.

This repository used to host a mix of experiments, including an early AI News Station page and the WanHuaTong text-to-video tool. Those active projects now live in dedicated repositories:

- **AI News Station:** https://github.com/yehloolau-afk/ai-news-station
- **WanHuaTong:** https://github.com/yehloolau-afk/wanhuatong
- **Personal site:** https://github.com/yehloolau-afk/yehloolau-afk.github.io

## Live Archive

https://yehloolau-afk.github.io/designer-tools-legacy/

## Contents

- `index.html` - legacy hub that points to the active projects and archived files.
- `ai-station.html` - compatibility redirect to AI News Station.
- `design-cockpit.html` - archived design cockpit experiment.
- `project.html` - archived project page.
- `data/`, `scripts/`, `.github/` - historical data and automation files retained for reference.

This repo is intentionally kept as an archive rather than an actively maintained product.
